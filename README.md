# מערכת מארגן ערב משחקים (Game Night Organizer)

תוכנית טקסטואלית אינטראקטיבית ב-Python לניהול מאגר משחקי קופסה וקבלת המלצות מדורגות מותאמות אישית לערב משחקים לפי מספר משתתפים, מגבלת זמן והעדפות סגנון.

## דרישות מערכת
- Python 3.8 ומעלה.
- ספריות: הספרייה התקנית בלבד (Standard Library) - ללא צורך בהתקנות חיצוניות (pip).

## הוראות הרצה
להפעלת המערכת:
```bash
python main.py
```
(בסביבת Windows בה פקודת python אינה זמינה, יש להריץ `py main.py`).

## הוראות הרצת בדיקות אוטומטיות
להרצת כל 6 בדיקות היחידה המקיפות:
```bash
python -m unittest discover -s tests -v
```

## יכולות המערכת בגרסת החובה
1. **הצגת מאגר נתונים וסיכומים:** הצגת רשימת המשחקים, ממוצע זמנים, וכמות המשחקים הכוללת.
2. **הוספת משחק עם ולידציה מלאה:** בדיקת תקינות מזהים כפולים, שלמות שדות וערכים חיוביים.
3. **חיפוש לפי תגית:** איתור מהיר של משחקים לפי קטגוריות (למשל "מסיבה", "אסטרטגיה").
4. **מנגנון המלצות מדורג (הלוגיקה המרכזית):** סינון קשיח של משחקים שאינם מתאימים למגבלות השחקנים או הזמן, חישוב ניקוד התאמה משוקלל, שבירת שוויון מובנית (לפי משך מקסימלי ולאחר מכן לפי א"ב), והפקת נימוק שקוף עבור כל המלצה.

## מגבלות ידועות
- הנתונים נשמרים בזיכרון התוכנית בלבד ומתאפסים עם היציאה (ללא מסד נתונים או שמירה לקובץ כפי שהוגדר בדרישות החובה).
- התוכנית מותאמת לממשק CLI טקסטואלי.
